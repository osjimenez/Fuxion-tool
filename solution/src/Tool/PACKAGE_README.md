`fx`, the tool of Fuxion's spaces, as a dotnet tool (a native executable for each platform; the .NET SDK 10 or
later installs it):
```
dotnet tool install -g Fuxion.Tool
fx --help
```
or once, without installing it: `dnx Fuxion.Tool`. Also from the releases of
[Fuxion-tool](https://github.com/osjimenez/Fuxion-tool/releases), with its install scripts.
